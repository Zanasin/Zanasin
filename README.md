## Hi, I'm Hasin Ishraq

Computer Science and Engineering undergraduate at the **Islamic University of
Technology (IUT)**, Bangladesh. I like working close to the hardware
(firmware, kernels and how systems really behave), and I also build machine
learning and full-stack web projects.

### Featured projects

- **[tscsync](https://github.com/Zanasin/tscsync)**: fixes the "TSC warp
  between CPUs" firmware bug on AMD machines before Linux boots, so the kernel
  keeps the fast TSC clocksource instead of HPET. C, UEFI, GRUB, Secure Boot.
- **[real-or-rendered](https://github.com/Zanasin/real-or-rendered)**: robust
  detection of AI-generated images across unseen generators and image
  degradation. Python, deep learning.
- **[UniSpace](https://github.com/Monajir/UniSpace_Web_Archi)** (team
  project): university room-booking platform with classroom bookings, faculty
  approval, schedules and notifications. React, Spring Boot, PostgreSQL,
  Redis, Podman.
